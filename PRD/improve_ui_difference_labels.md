# PRD - Mejora en diferenciacion de etiqueta manual y automatica
Estado: lanzado
Creado: 30/9/26

## Resumen
Hoy: Las lineas de etiqueta manual y automatica son identicas y generan confusion en el uso
Despues: Las lineas automaticas utilizadas por trim y las correcciones manuales se diferencian en color u otra variable para la diferenciación

## Historia
Hoy: El usuario se confunde entre la linea automatica y la manual
Despues: El usuario tiene feedback cual es la linea impuesta por metaheuristica o en un futuro un modelo de VAD o similar

## Objetivos / No-Objetivos
O1. Cambiar el color u otra variable visual de la linea manual al modificarla
